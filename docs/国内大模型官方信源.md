# 国内大模型官方信源（RSS / 列表页发现）

> **说明**：默认仓库 `.env` / `.env.example` **不**预填下列国内 `OFFICIAL_PAGE_URLS`；需要时再自行追加，并用 `scripts/verify_feeds_stdlib.py` 验证页面是否能发现 feed。

本仓库爬虫从 **`OFFICIAL_RSS_URLS`**（直连 RSS）与 **`OFFICIAL_PAGE_URLS`**（HTML 页内发现 `<link rel="alternate" type="application/rss+xml|atom+xml">`）拉取。多数国内官网为 **SPA 或无公开 RSS**，下列以「可发现 feed 的列表页」为主；若某页返回 0 条，属正常，可改用自建 [RSSHub](https://github.com/DIYgod/RSSHub) 生成 URL 填入 `OFFICIAL_RSS_URLS` 或 `X_RSS_URLS`。

## 验证单条 feed

```bash
cd backend
.venv/bin/python scripts/test_feed_fetch.py "https://示例/rss.xml"
```

批量复验（与 `crawler_service.discover_rss_links_from_page` 同源 HTML 解析；**不依赖 feedparser**）：

```bash
cd backend
python scripts/verify_feeds_stdlib.py
```

## 与 `source_labeling` 的关系

`backend/app/services/source_labeling.py` 中 `_LABEL_RULES` 按 URL 子串匹配展示名；新增国内域名后，同一 feed 在 `raw_items.source_name` 等字段会显示为中文品牌名。

## 可复制：`OFFICIAL_PAGE_URLS` 追加段

在现有 `OFFICIAL_PAGE_URLS` 末尾用英文逗号拼接（勿与已有 URL 重复）：

```text
https://www.deepseek.com/,https://tongyi.aliyun.com/,https://ai.baidu.com/tech,https://cloud.tencent.com/product/hunyuan,https://open.bigmodel.cn/,https://platform.moonshot.cn/,https://www.minimax.chat/,https://www.stepfun.com/,https://www.sensecore.cn/,https://www.volcengine.com/product/doubao,https://www.volcengine.com/news
```

部署到服务器后跑一次 `daily_rankings`（或等价采集任务），观察 `raw_items` / 日志。若某站为 SPA、无 `<link rel="alternate">`，该页不会产生条目，请换 **RSSHub 等生成的 RSS** 写入 `OFFICIAL_RSS_URLS`。
