Place the production QR images used by the About page in this directory:

- `wechat-group-qr.png`: WeChat contact or group QR code.
- `reward-qr.png`: reward/payment QR code for "请作者喝杯咖啡".

These filenames match the frontend defaults in `src/config.ts`. You can also override them with
`VITE_WECHAT_GROUP_QR_SRC` and `VITE_REWARD_QR_SRC` during the frontend build.
